# Consistency threshold calibration

Generated by `tools/calibrate.py` on 4000 synthetic shots (1167 drifted, 2833 consistent) using the mock provider's deterministic drift model (`DRIFT_RATE=0.3`).

Cost model: a false positive pays for one unnecessary regeneration (100¢); a false negative ships a bad shot (1000¢).

## Score distribution

| class | min | p50 | max |
|---|---|---|---|
| consistent | 0.991 | 0.991 | 0.995 |
| drifted | -0.467 | -0.001 | 0.504 |

Gap between the worst consistent score and the best drifted score: **0.487**. Any threshold inside that gap separates the classes perfectly on this dataset.

## Honest limitations

- The mock embedding space is bimodal: real image embeddings are continuous, so precision/recall will drop and this threshold must be recalibrated on labelled real generations.
- Both costs in the model are placeholders from the demo price table; the method (sweep + expected cost) is what transfers, not the exact 0.75.
- Regeneration is accepted after at most 2 attempts; the miss rate after two attempts is `DRIFT_RATE²` = 9.00% under this independent-drift model.
